# 🤖 AI Navigator

AI Navigator is a beginner-friendly AI tool discovery chatbot that helps users find the right AI tools for their tasks.

Instead of searching through hundreds of AI tools, users can simply describe what they want to accomplish. AI Navigator uses semantic search and an AI model to understand the request and recommend relevant tools.

## Features

- Natural-language chatbot
- AI-generated beginner-friendly responses
- Semantic search using Sentence Transformers
- AI tool recommendations
- Tool descriptions and use cases
- Direct links to recommended tools
- FastAPI backend
- Responsive web interface
- Environment-variable based API-key protection
